PRODUCT / CAPABILITY & BOUNDARY

A precise check.
A traceable result.

Migraven is a local-first utility for comparing agreed source and target exports before a migration checkpoint. Its value is not a green status. Its value is a review trail.

01 / INPUTS

Two formats.
One comparison model.

Both inputs are read locally and mapped into a shared record model. No cloud upload is part of the current product.

CSV

Delimited exports

UTF-8 CSV with quoted-field parsing, header and row-width validation, and support for a leading byte-order mark.

SUPPORTED INPUT
{ }

Flat-object JSONL

One flat JSON object per line. String, number, boolean and null scalar values are supported; nested arrays and objects are not.

SUPPORTED INPUT
02 / COMPARISON

Rules are explicit.
Results stay bounded.

The operator defines the unique key and up to 32 selected fields. Migraven applies exact string equality; it does not guess at business meaning.

01One non-empty, unique key in each export.REQUIRED
02One or more selected fields, up to 32.OPERATOR-DEFINED
03Exact string equality for each selected field.FIXED SEMANTICS
04Record-level differences and one-sided keys.HUMAN REVIEW
03 / DELIVERABLES

A compact evidence
package.

Each artifact serves a distinct review purpose. The package is generated from the supplied files and the selected comparison rules.

JSON

Comparison result

Machine-readable status, input filenames and row counts, per-field summaries, findings and row references.

HTML

Offline review report

A self-contained report for examining observed differences in a browser, without a hosted reporting service.

SHA

Integrity manifest

SHA-256 hashes and byte sizes for both inputs and the JSON report, checked by the local verifier.

PRODUCT DISCIPLINE

What Migraven does not claim.

  • It does not execute or transform a migration.
  • It does not map schemas or validate relationships.
  • It does not normalize dates, currencies or numeric values.
  • It does not infer business rules or explain root causes.
  • It does not certify completeness or overall migration correctness.
  • Its unsigned manifest does not establish authenticity.
