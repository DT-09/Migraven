PRODUCT / SCOPE

A focused verification
utility, not another ETL suite.

Migraven checks selected records and fields across two migration exports. It is built to produce a clear exception register for a migration lead to review—not to automate the sign-off decision.

REVIEW PACKAGE
DELIVERABLES

Four files. Four distinct jobs.

JSON

Comparison result

Field-level statuses, counts, observed values and source-row references. Suitable for downstream processing.

HTML

Offline review report

A self-contained view that a reviewer can open locally without a hosted dashboard.

CSV / REGISTER

Exception register

A practical list of differences and one-sided records for follow-up. Explanations remain with the reviewer.

SHA-256

Evidence manifest

Hashes and byte sizes bind the two input files to the generated JSON report. The manifest is unsigned and does not establish author identity.

BOUNDARIES ARE A FEATURE

What Migraven does
not claim to do.

It does not migrate data, transform schemas, connect directly to ERP systems, infer business meaning, normalize dates or currencies, validate relationships, or certify overall migration correctness.

A PASS means only that the selected field values matched for the paired keys under exact string comparison. A one-sided key is INDETERMINATE: the tool does not guess why the record is absent.
