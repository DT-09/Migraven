PRODUCT / CAPABILITY & BOUNDARY

Clarity at the
record level.

Migraven is a local-first verification engine for agreed source and target exports. It creates a structured exception register so a reviewer can see what differed, where it appeared and which rule was applied.

01 / INPUTS

Two formats.
One comparison model.

Both inputs are parsed locally into a shared row-and-column representation before the comparison engine runs.

CSV / UTF—8

Delimited exports

Quoted-field parsing, header and row-width validation, UTF-8 BOM handling and bounded file size.

SUPPORTED IN C17 CORE
{ }

Flat-object JSONL

02 / COMPARISON ENGINE

Explicit rules.
Predictable output.

The operator defines the unique key and selected fields. Migraven does not infer semantic equivalence or silently normalize values.

01Unique key

Non-empty and unique in both datasets.

REQUIRED
02Selected fields

Up to 32 fields, checked independently.

OPERATOR-DEFINED
03Equality

FIXED SEMANTICS
04Exceptions

Unequal values and keys present on only one side.

ROW-LINKED
05Decision

03 / DELIVERABLES

Evidence that stays
organised.

Each artifact has a defined purpose. Together, they make the comparison easier to inspect and preserve.

JSON

Comparison result

Machine-readable status, input row counts, per-field summaries, findings and source-row references.

HTML

Offline review report

A self-contained report that can be opened in a browser without a hosted reporting service.

SHA

Integrity manifest

SHA-256 hashes and byte sizes for the two input files and generated JSON result.

PRODUCT DISCIPLINE

Trust is built
by stating limits.

  • Does not execute or transform a migration.
  • Does not map schemas or validate relationships.
  • Does not normalize dates, currencies or numeric values.
  • Does not infer root causes or business meaning.
  • Does not certify completeness or overall correctness.
  • Its unsigned manifest does not establish author identity.
