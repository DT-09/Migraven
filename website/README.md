# Migraven product website

This is a static, multi-page product website. It is intentionally separate from the C17 application and does not upload, process or store customer files.

## Deploy

Use the **website/** directory as the static build output/root directory in Cloudflare Pages or another static host. No build command is required.

- Build command: leave blank
- Output directory: `website`
- Root directory: repository root

For a local preview, serve this directory with any static HTTP server. Opening `index.html` directly also works for the page navigation.

## Pages

- `index.html`: positioning and core promise
- `product.html`: workflow and deliverables
- `methodology.html`: status semantics and evidence limits
- `evaluation.html`: proposed paid evaluation scope and enquiry path
- `faq.html`: buyer-facing scope and trust boundaries

The visual system uses warm ivory, deep forest, muted brass and editorial serif typography. Google Fonts are optional; system fallbacks are defined.

## Before public deployment

1. Confirm the commercial license and evaluation terms with an adult responsible for the business.
2. Replace the GitHub Issues enquiry route if a controlled business contact channel is established.
3. Review the privacy/data-handling wording against the actual operating process.
4. Do not add a file-upload form unless a secure, documented data-handling system exists.
5. Keep all product limitations accurate. No customer references, certifications, accuracy claims or performance claims are asserted here.
