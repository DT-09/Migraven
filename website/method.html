METHOD / OBSERVATION TO EVIDENCE

Every result has
a defined meaning.

Migraven separates what the comparison observed from what a migration team must still determine. That distinction is central to responsible sign-off.

01 / EXECUTION SEQUENCE
01

Load

Read the source and target exports locally. Validate structure, headers and row widths.

02

Validate key

Require a non-empty unique key in each dataset. Invalid or duplicate keys stop the comparison.

03

Compare fields

Match records by key and compare each selected field using exact string equality.

04

Report

Write field summaries and findings with original source-row references.

05

Preserve

Generate an offline report and a manifest that can later check file integrity.

02 / RESULT VOCABULARY

Three statuses.
No hidden interpretation.

PASS

Matched under the selected rule

The key exists on both sides and the selected field values are exactly equal. This says nothing about fields that were not selected.

FAIL

Observed value difference

The key exists on both sides, but the selected field values differ. The difference requires investigation; it is not automatically a defect.

INDETERMINATE

One-sided key

The key appears in only one export. The comparison cannot determine whether the cause is omission, filtering, timing or a legitimate scope difference.

03 / INTEGRITY

Integrity is not
authenticity.

The manifest records SHA-256 hashes and byte sizes for the source file, target file and generated comparison JSON.

SHA
256

What verification establishes

The verifier can detect whether the recorded files still match the hashes and sizes in the manifest.

What it does not establish

The manifest is unsigned. It does not prove who created the files, that the original exports were complete, or that a manifest and files were not all replaced together. Use trusted storage or an independent signature process where stronger provenance is required.

04 / REPRODUCIBILITY

Run the bundled example.

The repository includes synthetic records and a demonstration script. It produces a comparison JSON, offline HTML report and evidence manifest.

python tools/demo.py

The demonstration uses bundled synthetic data. It is not customer evidence or a performance benchmark.
