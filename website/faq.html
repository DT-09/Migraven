QUESTIONS / ANSWERS

Clear limits.
Clear expectations.

The useful questions are the ones that prevent a mismatch between what a tool does and what a team expects it to prove.

Does Migraven migrate data?

No. It compares exports from two systems after a migration or test run. It does not move, transform or load records.

Which formats are supported?

CSV and flat-object JSONL. Nested JSON arrays and objects are not supported. JSONL records must use the same property names, though property order may differ.

Does PASS mean the migration is correct?

No. PASS means the selected field matched exactly for a paired key. It says nothing about unselected fields, source completeness, relationships, transformations or business meaning.

Does Migraven normalize dates, numbers or currencies?

No. Exact string equality is used. For example, 10 and 10.0 are different values. Agree normalization upstream if it is required.

Can it detect missing records?

It identifies keys present in only one input. It labels these INDETERMINATE because the cause could be extraction scope, timing, mapping or a genuine missing record.

Does it connect to our ERP or database?

No direct system connectors are currently included. The current workflow uses exports supplied by the evaluation team.

Are files uploaded to Migraven?

The current utility is local-first. The website does not accept file uploads. Any customer evaluation data transfer must be separately agreed through an appropriate secure process.

Is the evidence manifest tamper-proof?

No. It uses SHA-256 hashes and file sizes to detect changes relative to the recorded manifest. It is unsigned and does not establish author identity or prevent replacement of the manifest itself.

Is Migraven certified or independently security-audited?

No such certification or independent security assessment is claimed. Teams should evaluate it against their own technical, security and procurement requirements.

Can we use it commercially?

A license has not yet been selected. Do not redistribute or use it for a customer engagement until written license terms are agreed.
