PAID EVALUATION / INITIAL SCOPE

One export pair.
One clear review package.

A bounded Migration Export Verification Evaluation tests whether Migraven's selected-field comparison is useful against a real, well-understood migration checkpoint.

PROPOSED EVALUATION SCOPE

Keep the first engagement precise.

The initial scope is deliberately small. It validates a specific workflow before anyone discusses a wider rollout.

  • One source export and one target export.
  • One agreed unique key.
  • Up to three critical fields.
  • CSV or flat-object JSONL files.
  • JSON comparison result and offline HTML report.
  • Exception register with row references.
  • SHA-256 evidence manifest and a reviewer note.

Fee, timing, acceptance criteria, payment method, license grant and data-handling terms must be agreed in writing before the evaluation begins. No fixed price or delivery promise is implied here.

DATA HANDLING BOUNDARY

Do not send sensitive exports
through this website.

The website has no file-upload form. Do not email personal data, credentials, regulated records, or confidential production exports as an initial enquiry.

Start with a description of the system pair, export format, record scale and comparison objective. If a real dataset is later needed, agree a secure transfer method, permitted use, access, retention and deletion terms first. Synthetic or properly de-identified data is preferred for initial scoping.
