# Verity — paid pilot

## Offer

**Migration CSV Verification Pilot**

A fixed-scope review of one source export and one target export, using a buyer-approved unique key and one critical field per comparison run.

## Buyer receives

1. Input inventory: filenames, column headers and row counts.
2. Comparison outputs generated by Verity.
3. Exception register listing mismatched, source-only and target-only keys.
4. Source-row references for each finding.
5. A short review note separating observed differences from unresolved explanations.
6. A reproducibility note recording the exact command and tool version used.

## Pilot boundaries

- CSV files only.
- One source/target dataset pair.
- One unique key.
- Up to three critical fields, checked in separate runs.
- Exact string comparison only.
- No live database access, production credentials, or direct system changes.
- No claim that a mismatch is a migration defect until the buyer investigates it.
- No claim that a PASS proves business correctness, transformation correctness, or completeness beyond the configured checks.

The buyer must remove personal, confidential and regulated data before sharing files. Use synthetic or appropriately de-identified data for the first evaluation.

## Acceptance criteria

The pilot is complete when:
- both CSV files parse successfully or the input limitation is documented;
- the agreed key is present and unique in both datasets;
- each agreed field comparison has a machine-readable result;
- every generated finding includes the relevant source row reference;
- the buyer can reproduce the run from the recorded command;
- unresolved differences are explicitly listed rather than silently classified.

## Commercial structure

Sell this as a paid, fixed-scope evaluation—not a free custom build, open-ended consulting engagement, or promise of zero migration defects.

Agree scope, delivery date, fee, data-handling terms and payment arrangements with the responsible buyer before receiving any customer data. Do not accept production credentials or data you are not authorized and equipped to handle.

No public price is stated until delivery time and buyer willingness to pay have been tested.

## Pilot conversation

Ask the migration lead:
1. What source and target systems are being migrated?
2. Which exported datasets and fields are used for sign-off?
3. How are record-level differences found today?
4. What evidence must the client or delivery lead review?
5. Can they test the workflow on synthetic or de-identified CSV exports?

A paid pilot is justified only if the answers reveal a live, recurring need and an identified budget owner.
